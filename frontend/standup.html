Accepted formats:
• https://github.com/org/repo
• https://github.com/org/repo.git
• git@github.com:org/repo.git (SSH — needs key)
• /local/path/to/repo (local path)

Works with GitHub, GitLab, Bitbucket, Azure DevOps, and any other git host.

Commits on all branches are analysed, including unmerged feature branches.

For private repos, enter a Personal Access Token below.

Path or URL of the git repository.

Token formats by host:
• GitHub: Settings → Developer settings → Personal access tokens
• GitLab: User Settings → Access Tokens
• Bitbucket: Personal settings → App passwords
• Azure DevOps: User Settings → Personal access tokens

The token is only used for the git clone and is never stored.

Only needed for private repositories. Never stored.

Date Range

A quick range, or both custom dates.

End date must be on or after the start date.
