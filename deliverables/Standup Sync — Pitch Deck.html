Standup Sync
Your standup, written from the code.
Reads the actual code changes in a git repo and writes Slack, Email and Standup updates for developers and for clients.
standup-sync.onrender.com
## The problem
Every update starts with git log
$ git log --oneline
a41c2e9 fix stuff
9be07d1 wip
3f5a8c0 revert "fix stuff"
c72d19b more changes
e0b4f66 formatting
58ad2a3 update
Commit messages don't say what got done.
So developers open diffs, jump between branches and piece the week together by hand, before every standup, Slack post and client email.

## The solution
One click, six ready-to-post updates
1
Paste a repo URL. GitHub, GitLab, Bitbucket, Azure DevOps. Private repos with a token.
2
Pick a range. Last 24 hours to 30 days, or custom dates.
3
Press ⚡ Sync My Standup. Watch each step run live.
Format
Kept to
Slack
3–6 short bullets
Email
300 words, 2–4 sections
Standup
3 lines per person
Each one twice: for developers (files, functions) and for clients (plain English).

## How it works
Five steps, only two use AI
no LLM
Git repo
Every branch in your date range
no LLM
Noise filter
Drops merges, lock files, spacing-only changes, reverts
LLM
Read the diffs
One line per commit, tagged MAJOR or MINOR
no LLM
Highlights
Major updates only, by area and author
LLM
Outputs
Slack, Email, Standup for developers and clients
The model only sees commits that survive the filter: noise is dropped before any AI runs, and a typical run costs cents.
